# Coding Agent Instructions - Agent Framework BYO-AKS

This sample is a **Microsoft Foundry hosted agent**. It uses Microsoft Agent
Framework and the Responses protocol while hosting agent sessions on a
customer-managed AKS cluster.

## Deployment mode

- **Container deployment:** `docker.path` points to the Dockerfile that defines
  the agent image. Remote image builds are enabled.

## Key files

- `azure.yaml` - `azd` manifest that provisions the Foundry project and model
  deployment while registering existing AKS, identity, storage, and
  Application Insights resources
- `src/agent-framework-agent-basic-responses-byoaks/main.py` - agent
  implementation and Responses server entry point
- `src/agent-framework-agent-basic-responses-byoaks/pyproject.toml` and
  `uv.lock` - fully resolved Python runtime dependencies
- `src/agent-framework-agent-basic-responses-byoaks/Dockerfile` - container
  definition
- `README.md` - prerequisites and supported local run, test, and deployment
  paths

Do not commit `.vscode` launch or task files generated by the Foundry Toolkit.

## Dependency workflow

Follow `samples/python/hosted-agents/DEPENDENCY_POLICY.md`. Keep
`pyproject.toml` and `uv.lock` synchronized with `uv lock`, and validate with
`uv lock --check` and the repository dependency-policy checker.

## Development workflow

The BYO AKS, subnet, identities, storage account, and Application Insights
resources referenced by this sample must already exist. The manifest provisions
the Foundry project and model deployment. From the sample directory:

```bash
azd env new
azd env set AKS_RESOURCE_ID "<resource-id>"
azd provision
azd ai agent run
azd ai agent invoke --local "your message"
azd deploy
azd ai agent invoke "your message"
```

Do not add provisioning scripts that create the AKS cluster, subnet, managed
identities, storage account, or Application Insights resource.

## Runtime logging

Use the standard `logging` module for diagnostics emitted by the running hosted
agent. Do not use mutable framework log messages as E2E evidence.
