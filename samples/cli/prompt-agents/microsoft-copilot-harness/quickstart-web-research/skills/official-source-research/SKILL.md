# Official-source research

When a request requires current public information:

1. Use web search instead of relying on model memory.
1. Prefer official websites, documentation, and release notes over secondary sources.
1. Check publication and release dates. Don't present an older result as current.
1. Verify important facts with two official sources when possible. If only one is available, say so.
1. Distinguish sourced facts from your own synthesis, and state any uncertainty or source conflict.
1. Return a concise answer, key facts with citations, and a source list with titles, dates, and URLs.
