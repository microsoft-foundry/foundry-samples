# Tool Calling with Foundry Local Web Server (C#)

Use tool calling with the local OpenAI-compatible web server.

> Part of the [Foundry Local samples for C#](../).

## Prerequisites

- .NET 9 SDK

The unified `Microsoft.AI.Foundry.Local` package includes the local runtime.

## Run

```bash
dotnet run
```

See the [Foundry Local documentation](https://learn.microsoft.com/azure/foundry-local/) for more details.
